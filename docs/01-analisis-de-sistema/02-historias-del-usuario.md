# Historias de usuario

| ID | Módulo | Historia de usuario |
|---|---|---|
| HU01 | Admisión y Triaje | Como personal de admisión, quiero registrar a un paciente nuevo validando su DNI con el servicio de RENIEC, para evitar errores en sus datos de identificación. |
| HU02 | Admisión y Triaje | Como personal de admisión, quiero buscar a un paciente ya registrado y registrar su ingreso a una atención, para no duplicar su información. |
| HU03 | Admisión y Triaje | Como enfermero(a) de triaje, quiero registrar los signos vitales y el motivo de consulta y clasificar el nivel de urgencia, para priorizar la atención de los pacientes más graves. |
| HU04 | HCE | Como médico, quiero consultar la historia clínica completa del paciente (antecedentes, atenciones, recetas y resultados de laboratorio), para tomar decisiones clínicas informadas. |
| HU05 | HCE | Como médico, quiero registrar la evolución, el diagnóstico (codificado con CIE-10) y el tratamiento de una atención, para mantener actualizada la historia clínica del paciente. |
| HU06 | HCE | Como médico, quiero emitir una receta electrónica desde la atención, para que farmacia pueda dispensar los medicamentos indicados. |
| HU07 | HCE | Como médico, quiero solicitar exámenes de laboratorio desde la atención, para apoyar el diagnóstico del paciente. |
| HU08 | Farmacia y Laboratorio | Como farmacéutico, quiero gestionar el inventario de medicamentos (ingresos, stock y vencimientos), para asegurar su disponibilidad. |
| HU09 | Farmacia y Laboratorio | Como farmacéutico, quiero consultar y atender las recetas emitidas registrando la dispensación, para entregar los medicamentos correctos al paciente. |
| HU10 | Farmacia y Laboratorio | Como personal de laboratorio, quiero recibir las órdenes de exámenes y registrar sus resultados, para que queden vinculados a la historia clínica del paciente. |
| HU11 | Reportes Epidemiológicos | Como epidemiólogo, quiero generar reportes de casos por diagnóstico, zona y periodo, para realizar la vigilancia de salud pública. |
| HU12 | Alerta Epidemiológica Temprana | Como epidemiólogo, quiero recibir alertas automáticas cuando un diagnóstico aumente de forma inusual en una zona o periodo, para actuar de manera oportuna sin revisar manualmente los reportes. |
| HU13 | Explotación OLAP / BI | Como directivo del hospital, quiero consultar dashboards con indicadores de atención, diagnósticos y uso de recursos, para tomar decisiones de gestión. |
| HU14 | Administración | Como administrador del sistema, quiero gestionar usuarios, roles y permisos, para que cada persona acceda solo a la información que le corresponde. |
| HU15 | Administración | Como administrador del sistema, quiero gestionar los catálogos de diagnósticos, medicamentos y exámenes, para mantener estandarizada la información clínica. |
| HU16 | Administración | Como administrador del sistema, quiero consultar el registro de accesos a las historias clínicas, para garantizar la trazabilidad y la confidencialidad de la información del paciente. |
